# AAVISHKAR Image Assets

Drop real AAVISHKAR images into the correct subdirectory.
The website references these via `/images/<folder>/<filename>`.

## Structure

```
images/
  hero/
    main.jpg              — Hero section main visual (1408x1104 recommended)
  ai/
    neural-network.jpg    — AI Mission section large visual (1200x900)
  innovations/
    ai.jpg                — AI innovation area card
    software.jpg          — Software development card
    robotics.jpg          — Robotics & IoT card
    research.jpg          — R&D card
    entrepreneurship.jpg  — Entrepreneurship card
    emerging-tech.jpg     — Emerging technologies card
  projects/
    study-assistant.jpg   — AI Study Assistant project
    smart-campus.jpg      — Smart Campus project
    vision-guard.jpg      — VisionGuard project
    eco-track.jpg         — EcoTrack project
  research/
    ml.jpg                — AI & Machine Learning research
    vision.jpg            — Computer Vision research
    automation.jpg        — Automation & Robotics research
    sustainable.jpg       — Sustainable Technology research
  founder/
    portrait.jpg          — Founder professional portrait (800x1000)
  leadership/
    tech-lead.jpg         — Technology Lead portrait
    innovation-lead.jpg   — Innovation Lead portrait
    research-lead.jpg     — Research Lead portrait
    community-lead.jpg    — Community Lead portrait
    design-lead.jpg       — Design Lead portrait
  events/
    workshop.jpg          — Workshop event photo
    hackathon.jpg         — Hackathon event photo
    tech-talk.jpg         — Tech Talk event photo
    expo.jpg              — Project Expo photo
    meetup.jpg            — Research Meetup photo

  gallery/
    gal-1.jpg through gal-9.jpg  — Gallery masonry photos
  community/
    background.jpg        — Community CTA banner background (1600px wide)
```

## Image Guidelines

- **Format:** JPG or WebP preferred
- **Quality:** High resolution but optimized (under 500KB each ideal)
- **Faces:** For team/founder portraits, use consistent professional headshots
- **Style:** Maintain consistent blue-toned professional aesthetic
- **Alt text:** Edit descriptions in `src/data/siteImages.ts`
